Recommendation

for this fleet, today

Stay on Starter

13 actors, single-run-at-a-time, mostly zero-DOM API calls. 32 concurrent runs and 64 GB Actor RAM are far beyond what this fleet has ever asked for.

Move to Scale only once trailing monthly spend is consistently pushing past ~$150–190, i.e. approaching the $199 flat fee from below.

Re-test B&H's proxy setting

It's the one actor with a live incident history (4 silent-drain events) whose proxy default doesn't match that history — everything else either needs RESIDENTIAL and has it, or has tested clean and left it off.

A $7.50–8.00/GB residential run against B&H is cheap insurance against another drain.

Watch Grainger + Fisher + Jemtech spend

These three carry 100% of the fleet's proxy cost. If their combined residential GB grows, the Scale-tier proxy discount ($7.50 vs $8.00/GB) starts mattering before the CU rate does.

Run their actual GB/month through the calculator above whenever volume changes materially.

Ask about academic pricing before annual billing

Apify discounts annual paid plans 10% and has separately mentioned institutional discounts. Get a quote before locking in a year at Starter or Scale.

10% off Starter is only ~$1.90/mo — worth asking, not worth chasing.
  • Prepaid credit expires. Don't upgrade a tier just to "bank" unused capacity — unused balance does not roll over to the next billing cycle.
  • Rented Store Actors can bill differently. Some charge per event rather than per CU; check each Actor's own pricing page before folding it into this fleet's budget.
  • Test with a representative run — real auth, real page/category counts, real retries — before trusting a CU estimate. Apify's own guidance is the same: run it, then read the Billing → Usage view.
  • Plan limits aren't the whole governance story. Credential storage, workspace ownership, access review, and data retention sit outside this pricing page entirely and are worth a separate pass with university IT.
